Modo Real (Real Mode)

Dirección Física = (Segmento x 16) + Offset

¿Cómo funciona? (paso a paso)

Fórmula: Dirección Física = (Segmento × 16) + Offset

  1. El segmento (16 bits) se desplaza 4 bits a la izquierda (×16): en hexadecimal se le agrega un 0 al final.
  2. Se suma el offset (desplazamiento dentro de la ventana de 64 KB).
  3. El resultado es una dirección de 20 bits (1 MB: 0x00000–0xFFFFF). El 5.º dígito hex marca dónde está la ventana en la memoria física.

Ejemplo: 0x1234 : 0x00AB → 0x12340 + 0x00AB = 0x123EB

Modo Protegido (Protected Mode)

Dirección Lineal = Base (del descriptor) + Offset

¿Cómo funciona? (paso a paso)

En modo protegido el programa no da una dirección: da un selector + un offset. El hardware busca el descriptor, valida y recién ahí compone la dirección.

  1. Se descompone el selector en Índice / TI / RPL.
  2. Con el Índice se lee el descriptor en la GDT.
  3. Del descriptor se reconstruyen Base y Límite (y se leen P, DPL, S, Type, G…).
  4. Del descriptor se reconstruyen Base y Límite (y se leen P, DPL, S, Type, G…). El límite efectivo depende de G: con G=1 es (Límite × 1000h) + FFFh.
  5. Se valida protección: P=1, selector no nulo (0000–0003), índice dentro de la GDT, privilegio max(CPL, RPL) ≤ DPL y que los permisos del segmento permitan la operación pedida.
  6. Se valida Offset ≤ Límite efectivo (si no, #GP).
  7. Se calcula Dirección Lineal = Base + Offset.

El descriptor se escribe en orden de bytes de memoria (little-endian): el primer par de dígitos hex es el byte 0 (el menos significativo), no el más significativo.

Ejemplo: selector 0x23 (índice=4, GDT, RPL=3) + descriptor 0300000040F2C000 (bytes LE) + offset 0xA10 + CPL 0 → Base 0x400000 + 0xA10 = 0x400A10

Laboratorio de Reversing

Análisis de Descriptor de Segmento (64 bits)

¿Cómo funciona? (paso a paso)

Ingresa el descriptor completo en 64 bits binarios. La aplicación valida el ingreso (solo 0s y 1s, exactamente 64 bits), lo divide por colores según el esquema del 80386 y reconstruye Base, Límite y todos sus atributos.

  1. Base (32 bits) = Base[31:24] + Base[23:16] + Base[15:0].
  2. Límite (20 bits) = Límite[19:16] + Límite[15:0].
  3. Derechos de acceso: se decodifica el byte P·DPL·S·E·ED/C·R/W·A.
  4. Se describe qué se puede hacer en ese segmento (leer, escribir, ejecutar, usar como pila).
